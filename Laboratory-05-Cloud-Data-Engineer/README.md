# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This laboratory activity focuses on cloud object storage using MinIO, an S3-compatible open-source object storage server. The mission is to deploy MinIO using Docker, access its web console, create a storage bucket, and upload a sample object.

## Objectives

- Differentiate between Block, File, and Object Storage.
- Deploy an S3-compatible Object Storage server using MinIO and Docker.
- Access a cloud service through a web interface using port forwarding.
- Create a storage bucket and upload an object.
- Document cloud storage operations using Markdown.
- Maintain a structured Cloud Computing GitHub portfolio.

## Tools Used

- KillerCoda Playground (Ubuntu/Docker environment)
- Docker
- MinIO
- GitHub
- Modern web browser
- Markdown

## Skills Learned

- Comparing cloud storage types
- Running containerized cloud services
- Using Docker environment variables
- Accessing services through exposed ports
- Creating object-storage buckets
- Uploading objects to cloud storage
- Writing technical cloud documentation
- Organizing a GitHub cloud-computing portfolio
