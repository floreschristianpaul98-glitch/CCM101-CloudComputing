## 2. Short-Answer Questions

### **Q1: Which cloud provider offers the broadest range of services?**

AWS offers the broadest range of cloud services with 200+ distinct offerings across every category imaginable, from compute and storage to niche services like quantum computing and satellite communications. AWS's maturity since 2006 has allowed them to develop comprehensive solutions for virtually every enterprise use case, making it the default choice for organizations requiring maximum service diversity and flexibility.

### **Q2: Which provider best integrates with Microsoft technologies?**

Microsoft Azure provides seamless integration with the entire Microsoft ecosystem, including Windows Server, SQL Server, Microsoft 365, Active Directory, Dynamics 365, and Power Platform. Azure is the natural choice for organizations with existing Microsoft technology investments, offering unified licensing through Software Assurance, single sign-on capabilities, and tools specifically designed for Windows-based workloads and Microsoft enterprise applications.

### **Q3: Which provider is strongest in Artificial Intelligence and Kubernetes?**

Google Cloud Platform leads in both AI/ML capabilities and Kubernetes technology. GCP invented Kubernetes and provides the most mature managed Kubernetes service (GKE), while also excelling in machine learning through Vertex AI, BigQuery ML, and advanced data analytics. Organizations prioritizing AI innovation and containerized microservices should strongly consider GCP for its technological advantages in these domains.

### **Q4: Which cloud platform would you personally choose and why?**

The optimal choice depends on organizational context, but for balanced capabilities, AWS would be selected due to its unmatched service breadth, mature ecosystem, extensive documentation, and talent availability. However, organizations with Microsoft investments should choose Azure, while data-analytics-focused companies should prioritize GCP. The best cloud platform is the one that aligns with existing technology investments and specific business requirements.

## Key Observations

**Service Parity:** All three providers offer functionally equivalent services across core categories, though naming conventions and architectural approaches differ.

**Maturity Levels:** AWS services generally have the longest track record and largest community. Azure services excel in Microsoft integration scenarios. GCP services lead in data analytics and AI/ML domains.

**Cost Structures:** AWS offers extensive pricing models with Reserved Instances. Azure provides hybrid licensing benefits. GCP leads with per-second billing and automatic discounts without long-term commitments.

**Deployment Models:** All three support similar deployment architectures including multi-region, multi-zone, and hybrid cloud scenarios.
